# Archive

Scripts des premières expériences, qui ne font plus partie du projet final :
MLP NumPy, BiLSTM, baseline TF-IDF + régression logistique, CamemBERT de la phase 1.
Leurs poids ont été supprimés ; leurs résultats sont décrits dans `../RESULTATS.md` (phase 1).

Le projet final garde 3 modèles : SVM, CNN et CamemBERT (voir `../notebook_aura.ipynb`).
`../models/` ne contient plus que ces 3 modèles (CamemBERT = ensemble de 4 dossiers p2_*).
Les résultats de tous les essais CamemBERT sont dans `../results/recherche_camembert/`.
